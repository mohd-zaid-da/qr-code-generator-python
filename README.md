# 📱 QR Code Generator (Python)

A Python-based QR Code Generator that converts text or URLs into QR codes with customizable size, colors, and automatic file naming. This project demonstrates practical implementation of image generation, user input handling, and usage of external Python libraries.

---

## 🚀 Overview

This project allows users to generate QR codes with multiple customization options. It supports both command-line input and a GUI-based application.

The main goal of this project is to showcase Python development skills, including working with libraries, handling user input, and generating images programmatically.

---

## ✨ Features

- Generate QR codes from text or URLs  
- Customizable box size and border  
- Custom foreground (QR) and background colors  
- Automatic filename generation using timestamp  
- Input validation for better user experience  
- Error handling for invalid inputs
